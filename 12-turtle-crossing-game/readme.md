Turtle Crossing Game
A fun arcade game built with Python. 
You guide a little turtle across a busy road filled with moving cars. 
Reach the top safe to win a point and level up!

Game Rules
Start at the bottom of the screen.
Move up to reach the other side.
Avoid the cars moving sideways.
If a car hits you, the game ends.

Controls
Press w: Move up.

Note: You cannot move down, left, or right.
